# Framework: The Table Method

## Definition
The four-phase sequence that moves a household from mental overload to autonomous execution and meaningful connection.

## Components
- **Pause:** Stop the react cycle. Draw a line in the sand. Establish baseline capacity. (Supported by Battery Recharge Blueprint)
- **Clarity:** Map the invisible load. Identify what must run.
- **Alignment:** Set the rules. Distribute the architecture across the family.
- **Trust:** Execute autonomously. Verify the system runs.

## Function
Replaces reactive chaos with structured, self-sustaining household operations. Applicable to any family member for centering and stabilization.

## Application Context
Used to onboard families into Flo. Guides the weekly winddown, grocery planning, and daily execution flow.

## What It Replaces
Manual brain dumps, fragmented apps, and the belief that mothers must carry everything alone.

# Canonical Glossary: Household Operating Architecture

## Category Name
Household Operating Architecture

## Category Definition
A structural framework that treats the household as an autonomous system rather than a manual task list. It replaces constant input with established rules, automated guidance, and clear execution paths.

## The Reframe
Families do not need better calendars or more discipline. They need an operating system. The market treats homes as projects to manage; Household Operating Architecture treats them as systems to design.

## The New Game
A household that runs without daily intervention from the mother. Rules are set upfront. Execution is guided. Reminders handle the load. Capacity returns. Presence at the table becomes possible.

## Category Boundary
- This is not: A calendar app
- This is not: A coaching program
- This is not: A meal planning service
- This is: An autonomous operating system for family life
